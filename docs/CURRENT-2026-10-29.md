## Runtime evidence and limits

A private legacy-client version override allowed one held local client to enter Port San
d'Oria. Fontoumant dialogue reached the isolated JSONL sink and VanaVoice's generic Apple
Samantha `say` submission log at 20% volume. Duplicate frames were suppressed. Normal event
end option 0 made The Brugaire Consortium ACCEPTED on the server; VanaGuide advanced to
Abeaule, step 2 of 2. No quest was force-completed or accepted by a GM command.

This was a diagnostic, not strict acceptance. The initial position was off the mesh and an
unrelated Rhapsodies event was active. A teleport placed the fixture at the NPC, and release /
private runtime setup cleared the unrelated introduction. The next route had no target because
the graph ignored generated crossings. PR 33 fixes that source bug; its 16 offline checks and
1,418 existing assertions passed, but the new graph has not yet crossed a zone in a live client.

The client also rendered an unexpected key-item message after the parcel-giving quest handler.
Resource/version alignment is a plausible explanation, not a proven cause. A relaxed version
gate is not evidence of compatibility. Supported visual inspection was unavailable because
the computer-use RPC service was not configured. No alternate screenshot/focus mechanism was
used. Actual audible output, Pause/Resume/Skip/Stop, visible arrows and a two-quest unassisted
walk remain unverified. Raw dialogue and account evidence remain in ignored private storage.
