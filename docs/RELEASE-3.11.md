**On 3.10 or earlier? Download the `.dmg` below and drag FFXI on Mac into Applications, replacing the old copy.** Older versions will not update themselves to this one. Quit the game first.

**First open:** from 3.11 the app is signed but no longer notarized by Apple. macOS blocks the first open; allow it under **System Settings → Privacy & Security → Open Anyway**.

New here? Download the `.dmg`, drag **FFXI on Mac** into Applications, open it and press **Setup**.

### New
- **Phoenix XI.** Pick it in the world list and press **Connect Phoenix**. You sign in on Phoenix's own website, and the launcher installs Phoenix's official client into its own folder and starts it. You need an approved Phoenix account first. One client only, as Phoenix's rules require. Guide and voice addons stay off on Phoenix.
- A line at the top of the window says when the selected world has not approved this launcher. No world has yet, so it shows on every hosted world.
- More LandSandBoat worlds in the list, sorted by how many players are online.
- Optional multi-server play: a separate Windows environment per world, off by default.
- VanaGuide Server-Safe, a separate guide window for worlds that do not allow guide addons.
- As many clients per world as that world's rules allow.

### Fixed
- Update offers stay current, and Restart appears only when a verified update is ready.
- Logging out from the launcher sends a normal `/shutdown`.

### What has been tested
One Mac: an M1 MacBook Pro with 8 GB on macOS 27.2. Phoenix was played there on an existing install. Not yet tried: a first Phoenix install into a newly chosen folder, and Phoenix on any other Mac. Phoenix publishes an approved-tools list; this launcher has not been reviewed by Phoenix staff. Updating from 3.11 to a later version inside the launcher has not been tried yet. Reports are welcome in [Issues](https://github.com/danielalanbates/FFXI-on-Mac/issues).
