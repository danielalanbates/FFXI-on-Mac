# Content category buttons

The Server-Safe companion's Content column now uses full-width buttons for Start Here,
Jobs, Missions, and Quests. Click a category to expand or collapse its guides; categories
can stay open independently. Start Here is expanded initially. Guide buttons select the
route and reset its step to the beginning. A route selected by screen reading also opens
its category. Collapsing a category leaves the active route and progress unchanged.

Only categories with guides available for the selected server appear. Longer route names
wrap instead of being cut off. Buttons expose their expanded/collapsed state to accessibility.

This change affects navigation, not the route content or server level-cap rules.
